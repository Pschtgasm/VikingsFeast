# Viking’s Feast 1.4.1 – Änderungen

Quellcode-Buildpaket; keine kompilierte DLL enthalten. Auf Windows mit Valheim/BepInEx/Jötunn bauen.

## Konfiguration
Pro Gericht: `Food - <Id> / Enabled` (Neustart erforderlich). Standardmäßig deaktiviert: DeerThistleRoast, ForestHerbRagout, FrostSealStew, FrostberryBake, IcefjordFishPot, LoxHerbRoast, LoxMushroomPan, MistMushroomStew, MountainMushroomBroth, MushroomHoneyStew, NordicMooseRoast, NordicWildRoast, SeekerHerbRoast, SwampHerbSoup, VolcanicMeatStew

## Rezepte
Wildschwein-Kräuterbraten: TrophyBoar 1, Dandelion 5, Honey 3.
Blut-Seetang-Eintopf: umbenannt (Zutaten noch wie altes Rezept).
Wolfbraten: TrophyWolf 1, WolfMeat 4, Onion 4.
Drachenbrühe: DragonEggshellPowder 2, Onion 4, FreezeGland 2; 55 HP / 65 Ausdauer.
Zecken-Sud: Bloodbag 4, MeadowsHerbHarvest 2, Sap 2.
Herzhaftes Fladenbrot: BarleyFlour 10, Onion 3, LoxMeat 2. **Derzeit am Runenkessel, Kochofen-Ablauf noch nicht umgesetzt.**
Essenz des Ewigen Frosts: LiquidFrost 6, Kale 2, Lingonberry 5.
Elchburger: MooseMeat 2, BarleyFlour 4, Onion 2, Lingonberry 3; 105 HP / 45 Ausdauer.
Alle Nordgerichte benötigen Runenkessel-Stufe 4.

**Wichtig:** DragonEggshellPowder, MeadowsHerbHarvest, LiquidFrost, MooseMeat, Lingonberry etc. müssen als Prefabs in der installierten Mod-Kombination existieren; sonst wird das betreffende Rezept mit Warnung übersprungen. Die Icon-Zuordnung enthält nur eindeutig zuordenbare lokale Bilddateien; weitere besprochene Icon-Änderungen müssen vor einem finalen Release geprüft werden.
